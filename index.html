Abstract

Robot datasets are costly to collect and are usually tied to a specific embodiment, which makes it hard to reuse demonstrations across robots that differ in geometry, appearance and kinematics. We introduce UniLatent, a cross-embodiment transfer framework that avoids pixel-level image translation. UniLatent renders paired source–target robot observations in simulation and aligns a source visual encoder to a fixed target encoder, producing a shared latent space for policy learning. A policy trained on encoded source demonstrations can then be deployed on target observations through the target encoder. Across three simulation tasks and two target embodiments, UniLatent reaches up to 93% zero-shot transfer success and improves mean target success over the strongest pixel-translation baseline by more than 30 percentage points. In real-world xArm-to-Franka few-shot transfer, UniLatent completes 27 of 30 target rollouts, consistently outperforming target-only training and pixel-space translation pretraining.

The problem

A policy trained on Franka does not transfer to Sawyer.

In third-person camera views the robot occupies much of the image. Changing the arm alters appearance, self-occlusion, contact geometry and the visibility of task-relevant objects all at once, so a vision-based policy that succeeds in-domain can fail outright on new hardware. Both clips below run the same task from the same source demonstrations.

On the source Franka the very same policies reach 80–89% on this task. Prior work closes this gap by editing the source frames — masking, inpainting or diffusion-based robot generation — but then the policy consumes edited pixels, so segmentation errors, distorted grippers and inconsistent contact regions propagate straight into closed-loop control.

The idea

Align representations, not pixels.

We render large numbers of paired observations in which a source and a target robot hold the same tool-center-point pose under the same camera and the same randomized scene. These pairs supervise a source encoder to map source images into the latent space of a frozen target encoder. The renderer only has to establish cross-robot correspondence; it never has to look photorealistic, because the policy never consumes a rendered target image.

Why freezing the target encoder matters

Because the target encoder is never updated, the features observed at deployment are produced by exactly the model that defined the alignment objective. Training only the source encoder asks a source image to produce the representation associated with the matched target observation, rather than forcing both domains into an unconstrained shared space that neither robot occupies at test time.

Why latent transfer helps

Decoded frames look right and act wrong.

A translated target-looking frame can preserve global scene layout while getting the wrist, the gripper opening or the object contact region subtly wrong — and a closed-loop policy amplifies exactly those errors. UniLatent uses the same paired-rendering information to align features, but never trains the policy on synthesized target pixels.

Limitations

What this does not cover

UniLatent currently targets single-arm robots with parallel-jaw grippers and a shared end-effector action interface. Extending to dexterous hands, mobile manipulators, or tasks that require tool-specific contact would need additional retargeting and contact modeling. The method also assumes the target robot can complete source tasks within a comparable workspace; demonstrations outside the target's reachable set may need trajectory modification. Our real-world evaluation uses a single physical setup, so tests under broader background and object variation remain future work.
